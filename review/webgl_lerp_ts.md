# webgl/lerp.ts 源码分析

## 文件概述

**路径**: `src/webgl/lerp.ts`  
**大小**: 11KB  
**功能**: 着色器中的线性插值函数 - GPU 端插值实现  
**许可证**: Apache License 2.0

## 核心功能

### 1. 1D 线性插值

```glsl
float lerp(float a, float b, float t)
// 返回 a + (b - a) * t
```

### 2. 2D 双线性插值

```glsl
float lerp2(float a00, float a10, float a01, a11, vec2 t)
// 在 2D 网格上进行双线性插值
```

### 3. 3D 三线性插值

```glsl
float lerp3(...)
// 在 3D 网格上进行三线性插值
```

## 插值类型

| 类型 | 维度 | 用途 |
|------|------|------|
| lerp | 1D | 基本线性插值 |
| lerp2 | 2D | 双线性插值 |
| lerp3 | 3D | 三线性插值 |

## 在体数据渲染中的应用

切片视图渲染需要从 3D 体数据中采样：
- 使用三线性插值获得平滑的切片图像
- GPU 上并行计算

## 知识点

- **线性插值**: a + (b-a)*t
- **双线性插值**: 2D 网格上的插值
- **三线性插值**: 3D 体数据的标准采样方式
- **GPU 并行**: 纹理采样在 GPU 上并行执行
