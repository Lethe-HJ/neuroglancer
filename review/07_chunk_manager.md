## 核心概念

### 1. Chunk (数据块)

体数据被分割成固定大小的块（chunks）进行管理：
- 支持多级细节 (LOD)
- 按需加载
- 缓存管理

### 2. ChunkManager

```typescript
class ChunkManager extends RefCounted {
  // 协调数据块的加载
  // 管理缓存
  // 处理优先级
}
```

### 3. ChunkQueue

- 请求队列管理
- 优先级排序
- 并发控制

## 主要功能

1. **数据分块**: 将大体数据分割为可管理的小块
2. **按需加载**: 只加载可见区域的数据
3. **多级细节 (LOD)**: 根据缩放级别加载不同分辨率
4. **缓存管理**: 内存和磁盘缓存
5. **预取**: 预测性数据加载
