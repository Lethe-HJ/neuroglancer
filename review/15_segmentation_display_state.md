# segmentation_display_state 源码分析

## 文件概述

**路径**: `src/segmentation_display_state/`  
**功能**: 分割显示状态 - 神经分割区域的显示控制  
**许可证**: Apache License 2.0

## 核心模块

### 1. frontend.ts (40KB)

分割显示前端

**主要功能**:
- 分割颜色管理
- 选中状态
- 可见性控制

### 2. property_map.ts (40KB)

属性映射

**功能**:
- 分割属性（颜色、名称等）
- 等价关系
- 颜色生成

## 核心概念

### Segment (分割)

神经分割的基本单元：
- 唯一 ID
- 颜色
- 名称
- 属性

### SegmentSet (分割集)

- 可见分割集
- 隐藏分割集
- 选中分割集

## 主要功能

1. **颜色映射**: 自动生成/手动设置颜色
2. **选中管理**: 高亮、选中状态
3. **可见性**: 显示/隐藏特定分割
4. **合并/分割**: 分割区域操作
