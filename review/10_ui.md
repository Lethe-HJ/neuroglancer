## 核心概念

### Tool (工具)

Neuroglancer 使用工具系统处理用户交互：
- 选择工具
- 绘制工具 (点、线、框等)
- 测量工具
- 导航工具

### SidePanelManager

```typescript
class SidePanelManager {
  // 注册面板
  // 面板布局管理
  // 面板可见性控制
}
```

## 主要功能

1. **图层管理 UI**: 图层列表、属性编辑
2. **工具面板**: 工具选择和配置
3. **截图功能**: 导出当前视图
4. **状态编辑**: JSON 状态编辑
5. **帮助系统**: 快捷键帮助
