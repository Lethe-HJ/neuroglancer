# mesh 源码分析

## 文件概述

**路径**: `src/mesh/`  
**功能**: 网格渲染 - 3D 网格模型显示  
**许可证**: Apache License 2.0

## 核心模块

### 1. frontend.ts (37KB)

网格渲染前端

**主要功能**:
- 网格加载
- 渲染调度
- LOD 管理

### 2. backend.ts (29KB)

网格数据后端处理

### 3. multiscale.ts (13KB)

多尺度网格

**支持**:
- 不同细节级别
- 渐进加载

### 4. triangle_strips.ts (11KB)

三角形带优化

### 5. draco/

DRACO 压缩网格支持

## 主要功能

1. **网格加载**: 从各种数据源加载网格
2. **LOD**: 多细节级别
3. **渲染优化**: 三角形带、批处理
4. **压缩支持**: DRACO 压缩

## 与其他文件的联系

- **依赖**: `webgl/` - WebGL 渲染
- **依赖**: `chunk_manager/` - 数据块
- **被引用**: `layer/single_mesh/` - 单网格图层

## 知识点

- **3D 图形**: 网格数据结构
- **DRACO**: Google 3D 压缩
- **LOD**: 多细节层次
- **渲染优化**: 批处理、实例化
